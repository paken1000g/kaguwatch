Groq APIキー取得手順（無料・2分）
01
console.groq.com を開く
console.groq.com にアクセス。Googleアカウントで即登録できます。
02
「API Keys」→「Create API Key」
発行された gsk_... の文字列をコピー。クレカ不要。
03
このページの「Groq API キー」欄に貼り付けて「保存」
1日14,400リクエスト無料。レビュー1本=1リクエスト。
Fanza（DMM）APIキー取得手順
01
DMMアカウント作成
dmm.com でアカウント登録（無料）。年齢確認が必要。
02
DMM アフィリエイト登録
affiliate.dmm.com でアフィリエイト会員登録。審査2〜3営業日。
03
DMM Web サービス API 申請
承認後、affiliate.dmm.com/api/ から申請。API ID とアフィリエイト ID が発行されます。
